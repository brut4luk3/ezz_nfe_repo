# Monorepo Setup (Flutter + Firebase)

Checklist de comandos para executar manualmente no terminal, na ordem.

## 1) Ir para a raiz do repositório
```bash
cd c:/Users/lucas/Desktop/DevProjects/ProjetosMobileDev/ezz-nfe_repo
```

## 2) Criar o projeto Flutter dentro de `app/` (somente Android)
```bash
flutter create app --platforms=android
```

## 3) Inicializar Git na raiz
```bash
git init
```

## 4) Conferir status dos arquivos
```bash
git status
```

## 5) Adicionar tudo ao primeiro commit
```bash
git add .
```

## 6) Criar o primeiro commit
```bash
git commit -m "chore: bootstrap monorepo structure"
```
